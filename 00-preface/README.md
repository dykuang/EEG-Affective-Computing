# Preface

This book is a step-by-step guide to deep learning for EEG-based emotion recognition in affective computing.

It is written to move from foundations to implementation:

- what EEG is and how it is measured
- what affective computing means in the context of emotion recognition
- how deep learning methods are used for EEG signals
- how to build, train, and evaluate practical models

The book is intentionally structured so each chapter can be expanded gradually as the project grows.

See the [Authors](authors.md) page for the collaboration note used in this book.
