# EEG-Affective-Computing
A repo for hosting my online "book" for EEG based emotion classification from past explorations


### 
Local preview while writing (fast feedback)
Use HonKit (the maintained GitBook-compatible tool) locally.  

From repo root, run:  
```
npm init -y
npm install --save-dev honkit
npx honkit serve  
```  
Open http://localhost:4000 to preview instantly.
Keep it running while editing; refresh browser to see changes.
